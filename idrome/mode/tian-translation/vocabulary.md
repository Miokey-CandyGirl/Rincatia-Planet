# 田语词库（Vortaro de Ketiá）

本词库整理自《现代琳凯蒂亚语 v26.5》（华田中央大学田语学院，田野主编），收录田语核心词汇、词根派生关系及常用词汇表，供 iDrome 田语模式翻译与解析使用。

## 一、词汇基础规则

### 词性与词尾对应

田语词根通过添加不同元音词尾派生出四种词性：

| 词性 | 词尾（通常） | 指代内容 |
|------|--------------|----------|
| 名词（n.） | O 列元音（-o, -ō, -ô） | 事物、概念 |
| 动词（v.） | E 列元音（-e, -ē, -ê） | 动作、过程 |
| 形容词（adj.） | A 列元音或 -i（-a, -ā, -â） | 性质、状态 |
| 副词（adv.） | U 列元音或 -li（-u, -ü, -û） | 方式等 |

### 构词法公式

```
单词 =（前缀）+ 词根/派生词 +（后缀）
```

- 词根数量唯一，前缀、后缀、派生词数量不限
- 词缀改变词的核心语义（构词行为），词尾是语法标记
