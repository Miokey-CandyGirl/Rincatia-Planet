# 田语语法规则（Gramatiko de Ketiá）

本语法规则整理自《现代琳凯蒂亚语 v26.5》（华田中央大学田语学院，田野主编），涵盖田语语音、词语、句式、示词、名词、动词、辅词、代词、数词、连词、领语、结语等完整语法体系，供 iDrome 田语模式翻译与解析使用。

## 规则2：词语（Vorto）

### 2.1 词语分类

#### 按数量分类

| 类型 | 包含词类 | 特征 |
|------|----------|------|
| 有限词 | 代词、数词、连词、示词、抒情词 | 封闭类，无词尾变化，不参与词根派生 |
| 无限词 | 名词、动词、形容词、副词、声叹词 | 开放类，有词尾变化，源自 2000 词根表 |

#### 按来源分类

- **外来词**：依田语语音规则及构词法将外语拉丁拼写转为对应形式，语意可能变化
- **古有词**：类似汉语成语的固定表达，需整体记忆
- **标准词**：田语规定且固定的 2000 个词根（无限标准词）+ 所有有限词（有限标准词）

### 2.2 词尾

| 词尾类型 | 附着对象 | 功能 | 示例 |
|----------|----------|------|------|
| 集群词尾 -on | 名词 | 表"们、群" | soseon 学生们 |
| 方位词尾 | 名词 | 构成空间名词 | dekowo 桌子上 |
| 趋向词尾 | 动词 | 表位移方向 | eto 前往 |
| 体词尾 | 动词 | 表动作时间状态 | libele 写过 |
| 比较词尾 | 辅词 | 表比较等级 | belatē 更美 |

### 2.3 构词法公式

```
单词 =（前缀）+ 词根/派生词 +（后缀）
```

- 词根数量唯一，前缀、后缀、派生词数量不限
- 词缀为构词范畴，非语法标记
- 示例：bel-（美）→ bela（美丽的）→ mubela（丑的）→ kebele（使美丽）→ kebelenio（美容院）

## 规则3：句式（Sintako）

### 3.1 句子范式

田语标准句的默认语序为 **S + V + O**。一个标准句只能有一个核心主语（S）、一个核心述语（V）、一个核心宾语（O）。

**标准句公式：**

```
Σ ＝ [H] + S(α+ s) + V(β+ v) + O(γ+ o) + [E] + P
```

| 符号 | 成分 | 定义 | 充任词类 |
|------|------|------|----------|
| Σ | 标准句 | 能独立表达完整语义，可还原为 S+V+O 结构 | — |
| H | 领语 | 句首语用成分，承载强调或祈使 | 强调词、牵词 |
| S | 主语 | 陈述动作变化或关系的对象 | 名词性短语或子句 |
| α | 主辅 | 主语内部的修饰语 | 形容词、形容词性短语 |
| s | 主元 | 主语的核心 | 体词、名词性短语 |
| V | 述语 | 表示主语的变化或主语与宾语的关系 | — |
| β | 述辅 | 述语内部修饰语 | 副词、副词性短语 |
| v | 述元 | 述语的核心 | 动词、系动词 |
| O | 宾语 | 动作或关系所直接涉及的对象 | 名词性短语或子句 |
| γ | 宾辅 | 宾语内部的修饰语 | 形容词、形容词性短语 |
| o | 宾元 | 宾语的核心 | 体词、名词性短语 |
| E | 结语 | 句末语用成分 | 前止词、后止词 |
| P | 句末标点 | 辅助表达语气或边界 | 句号/感叹号/问号 |

### 3.2 三种句子类型

#### 变化句（Σc）

述元为不及物动词，表示主语自身的变化（动作、性质、状态的变化）。事件只有一个核心参与者（主语）。

```
公式：Σc = [H] + S + V + [E] + P
示例：Hi dormelē yo. 他睡着了。
结构：S(Hi) + V(dormelē) + E(yo)
```

#### 关系句（Σr）

述元为系动词 es（是）或 ez（有/在），表示主语与宾语之间的静态关系。

```
公式：Σr = [H] + S + V + O + [E] + P
示例：Ŝi es bela yo. 她是漂亮的。
结构：S(Ŝi) + V(es) + O(bela) + E(yo)
```

#### 变化关系句（Σcr）

述元为及物动词（系动词除外），表示主语通过自身变化作用于宾语。

```
公式：Σcr = [H] + S + V + O + [E] + P
示例：Wi libele libo yo. 我写过书。
结构：S(Wi) + V(libele) + O(libo) + E(yo)
```

### 3.3 多重述辅顺序

多个述辅同时出现时，推荐顺序：

```
述辅（时间 + 空间 + 方式 + 频率 + 其他）+ 述元
示例：Wi legen xu sosenio ku sōhu kure yo. 我昨天在学校快速地跑。
```

### 3.4 重要概念

- **分句**：由连词连接或由非句末标点连接的两个及以上句子中的任意一个
- **词性短语**：具有某一词性属性的短语（名词性短语、动词性短语等）
- **子句**：充当标准句中某一语法成分的句子
- **单成分与成分序列**：一个成分由一个单词充任为"单XX"，由两个及以上词语充任为"XX序列"

## 规则4：示词（Ŝicio）

示词是田语最核心的语法系统，标明其前方成分在整个句子中的句法角色。田语共有 15 个示词。

### 4.1 主语示词

| 示词 | 简写 | 功能 | 示例 |
|------|------|------|------|
| wô | 'ô | 主语自发示词（有生命物主动施动） | Wi wô elāle yo. 我主动来了。 |
| jio | 'j | 主语他发示词（无生命物受动/被动） | Wi jio pulelēm hi par. 我被他打了。 |
| lio | 'l | 主语抽象示词（性质/状态/抽象概念/子句名词化） | Hapia lio es bona. 幸福是好的。 |

### 4.2 宾语示词

| 示词 | 简写 | 功能 | 示例 |
|------|------|------|------|
| par | 'p | 宾语静态示词（处置对象/比较基准/被动施动者） | Wi pagezē hi'p eslē puta. 我把他打肿了。 |
| pon | 'pn | 宾语动态示词（传递终点/使役对象/受益对象） | Wi pone hi'pn ezge i pāo. 我给他一杯水。 |

### 4.3 述辅示词

| 示词 | 简写 | 功能 | 示例 |
|------|------|------|------|
| du | — | 普通述辅示词（…地） | 方式状语标记 |
| xu | — | 述辅时间示词（在…时候） | Wi legen xu etole. 我在昨天去了。 |
| ku | — | 述辅地点示词（在…地点） | Wi Jōŋgûg ku ekelāle. 我来自中国。 |
| peyoŋ | 'py | 述辅方式示词（用/以/因/花了） | 表工具/方式/原因 |
| poroŋ | 'pr | 目的示词（为了） | XioMiŋ mide libo poroŋ eto libonio. 小明去图书馆看书。 |

### 4.4 主宾辅示词

| 示词 | 简写 | 功能 | 示例 |
|------|------|------|------|
| da | 'a | 普通主宾辅示词（…的） | Wia amiko'a libo. 我朋友的书。 |
| xa | — | 主宾辅时间示词（…的时间） | Togen xa luno. 明天的月亮。 |
| ka | — | 主宾辅地点示词（…的地点） | Faminio ka mono. 家里的东西。 |

### 4.5 其他示词

| 示词 | 功能 | 示例 |
|------|------|------|
| am | 关涉示词（涉及/关于/对于） | Ko mono am, wi mōje. 关于这件事，我不知道。 |
| li | 句状语示词（修饰整个句子） | Caŋ li win perite libo. 我们都读书。 |

## 规则5：名词（Nomo）

名词 = 名、动、形、副 +（集群词尾）+（方位词尾）。名词以 O 列元音（o, ō, ô）结尾为典型标志。

### 5.1 集群词尾 -on

附着于名词后，表示"们、一些、群"的集群属性。

| 形式 | 含义 | 示例 |
|------|------|------|
| 名词原形 | 个体或类指 | soseo 学生 |
| 名词 + -on | 群体、若干 | soseon 学生们 |

### 5.2 方位词尾

名、动、形、副 + 方位词尾构成复合名词，将空间位置名词化。

#### 方位关系（6种）

|  | 接壤（接触） | 不接壤（悬浮） |
|------|------|------|
| 内部 | -θinē + 方位词 | -nē + 方位词 |
| 外部 | -θiwā + 方位词 | -wā + 方位词 |
| 不考虑内外 | -θi + 方位词 | 直接加方位词（日常简化） |

#### 方位词（18个）

| 类别 | 方位词 | 含义 |
|------|--------|------|
| 基本方向 | -ezor / -ayor / -qin / -hô / -joŋji / -wā | 左/右/前/后/中/外 |
| 地理方向 | -elasï / -wesï / -suθï / -norθï | 东/西/南/北 |
| 空间范围 | -nē / -hüji / -eto / -qiko / -wo / -lu | 内/附近/紧挨/周围/上/下 |
| 动态趋近 | -etole / -toeto | 靠到/靠去 |

### 5.3 形式名词

形式名词 **o** 不指代具体事物，作为语法占位符或宿主。相应还有形式动词 e、形式形容词 a、形式副词 u。

- **承载方位词尾**：Oelasï'l ez tāyaŋ. 东边有太阳。
- **占位施动者**：o'pn = 形式名词 o + 宾语动态示词简写 'pn
- **抽象句法模板**：O kû o'pn e o. 某人让某人做某事。

## 规则6：动词（Verbo）

动词 = 名、动、形、副 +（趋向词尾）+ 体词尾。动词以 E 列元音（e, ē, ê）结尾为典型标志。动词的否定用前缀 ne。

### 6.1 趋向词尾（32个）

| 方向 | 原形 | + lā（来） | + to（去） |
|------|------|------------|------------|
| 上 | -wo | -wolā 上来 | -woto 上去 |
| 下 | -lu | -lulā 下来 | -luto 下去 |
| 出 | -ĉu | -ĉulā 出来 | -ĉunēn 出去 |
| 进 | -jio | -jiolā 进来 | -jioto 进去 |
| 回 | -gaŋ | -gaŋlā/-olā 回来 | -gaŋto/-oto 回去 |
| 过 | -ke | -kelā 过来 | -keto 过去 |
| 起 | -hē | -hēlā 起来 | -hēto 起去 |
| 开 | -gâ | -gâlā 开来 | -gâto 开去 |

**形式动词 e**：趋向词尾不可独立使用，须接在形式动词 e 后。

### 6.2 体词尾（9×2）

| 体名 | 正向体 | 逆向体 | 核心语义 |
|------|--------|--------|----------|
| 一般体 | 原形 | -en | 默认动作 / 被动 |
| 计划体 | -ge | -gen | 打算做 / 被打算 |
| 起始体 | -gē | -gēm | 开始做 / 被开始 |
| 进行体 | -ze | -zen | 正在做 / 被正在 |
| 终止体 | -zē | -zēm | 恰好做完 / 被恰好 |
| 结果体 | -lē | -lēm | 已经做完 / 被动完成 |
| 经验体 | -le | -len | 曾做过 / 曾被做 |
| 惯常体 | -re | -ren | 经常做 / 被经常 |
| 短时体 | -rē | -rēm | 做一下 / 被做一下 |

**逆向体 = 被动语态**，田语通过体词尾的逆向形式直接表达被动。

### 6.3 时间副词搭配

| 时间副词 | 含义 | 示例 |
|----------|------|------|
| θuu | 过去 | θuu libele 过去写过 |
| pθuu | 刚刚 | pθuu libelē 刚刚写完 |
| zïli | 现在 | zïli libeze 正在写 |
| czïli | 依旧/一直 | czïli libere 一直写 |
| joli | 将来 | joli libege 将要写 |
| bjoli | 即将/马上 | bjoli libelē 马上写完 |

### 6.4 系动词

| 类型 | 公式 | 含义 | 示例 |
|------|------|------|------|
| 判断系动词 es | A es B | A 是 B（等同） | Ŝi es bela. 她是漂亮的。 |
| 近似 ese | A ese B | A 像 B（近似） | Ŝi ese bela. 她像是漂亮的。 |
| 不同 nes | A nes B | A 不是 B | Ŝi nes bela. 她不漂亮。 |
| 存在系动词 ez | A ez B | A 在 B / B 有 A | Libro ez dekowo. 书在桌子上。 |
| 可能 eze | A eze B | A 可能在 B | — |
| 不可能 nez | A nez B | A 不在 B | — |

### 6.5 形容动词与名动词

- **形容动词**：形容词 + 体词尾，表"变成"。如 putize 正在变紫。
- **名动词**：名词 + 体词尾，表"成为"。如 sensejiarlē 成为教师。

### 6.6 使役结构

使役动词 kû 充任核心述元，使役对象必须带动态示词 pon（简写 'pn）。

```
结构：o kû o'pn.
示例：Ŝi kûze wi'pn eslē ce-hapi. 她现在让我很开心。
```

### 6.7 动词的并列禁止

田语严格禁止两个动词在同一个标准句中并列充当核心述元。次要动词必须：
- 用连词连接，或
- 用示词降级为修饰成分

### 6.8 连动句与共动句

- **连动句**：表目的用 poroŋ，表顺序用 kuni，表方式用 peyoŋ，表反复用 hâ
- **共动句**：同一施动者同时进行用 yixo，不同施动者同时做相同动作用 yixoli，互指共动用 samhō

## 规则7：辅词（Modifo）

辅词包含形容词和副词两大类。

### 7.1 辅词的构成

形容词/副词 = 名、动、形、副 + 辅词词尾。

| 词尾 | 类型 | 语义特征 |
|------|------|----------|
| -a | 强形容词 | 强烈、夸张、鲜明；表性质 |
| -i | 弱形容词 | 弱情感、含蓄；表状态 |
| -u / -li | 副词 | 基本方式 |

### 7.2 比较词尾

| 等级 | 形容词词尾 | 副词词尾 | 语义 |
|------|------------|----------|------|
| 原级 | -i / -a | -u / -li | 基本性质或方式 |
| 相同级 | -ixo | -ixo | 与…一样… |
| 比较级 | -tē | -tē | 比…更… |
| 最高级 | -sā | -sā | 最… |

### 7.3 比较句

- **最高级**：Ŝi es belasā xovrino. 她是最好看的小女孩。
- **比较级**（有宾语时形容词动词化）：Wi belatē ŝi'p. 我比她漂亮。
- **相同级**：Wi hâ ŝi es belaixo. 我和她都很美。

## 规则8：代词（Qinnomo）

代词为有限词。详见词库中的人称代词表与相关词表。

### 代词类型

- **基本型**：wi/ni/hi/ŝi/ji
- **复型**（-n）：win/nin/hin/ŝin/jin
- **敬型**（-câli）：wicâli/nincâli 等
- **谦型**（-zo）：izo/nizo 等
- **物主**（-a）：wia/nia/hia 等
- **反身**（-ẑi）：wiẑi/niẑi 等

## 规则9：数词（Numero）

数词为有限词（封闭词类）。详见词库中的基数词表。

- 基数词几乎全为单音节
- 数字组合遵循"高位在前，低位在后"原则
- 1~9 后面紧跟"百、千"等数词时表示乘法关系

## 规则10：连词（Kunio）

连词连接两个及以上的分句或词语，形成逻辑关系。

### 10.1 联合关系

| 连词 | 含义 | 示例 |
|------|------|------|
| hâ | 和/与/且 | piŋgō hâ pisâŋo 苹果和香蕉 |
| kowe | 此外/还 | — |
| ole | 并且/而且 | Ŝi bela ole mōla. 她美丽而且温柔。 |
| hâda | 仍然/还是 | Hâda mōje. 还是不知道。 |

### 10.2 对立关系

| 连词 | 含义 |
|------|------|
| kona | 或者/还是 |
| sedo | 但是 |
| vakan | 虽然/尽管 |
| nega | 相反 |
| cedo | 却/偏偏 |
| tamen | 然而/可是 |
| nes...ses | 不是…而是 |

### 10.3 因果关系

| 连词 | 含义 |
|------|------|
| qavi | 因为 |
| gosi | 因此/所以 |
| silo | 因此/那么 |
| caŋli | 总之 |
| kuni | 则/然后/接续 |
| doẑo | 导致 |

### 10.4 条件关系

| 连词 | 含义 |

## 规则11：领语（Hedo）

领语是始终位于句首的语用成分，承载强调或祈使。

### 11.1 祈使句

通过牵词（祈使词）置于句首完成表达。

| 牵词 | 功能 | 示例 |
|------|------|------|
| celoŋ | 请（礼貌请求） | Celoŋ onin czïli purie sensenio! 请大家保持教室干净！ |
| hepom | 请求 | Hepom ni helpe wi'pn. 请求你帮帮我。 |
| nuden | 禁止 | Nuden ope ko pordo! 禁止打开这扇门！ |
| den | 允许 | Den wi jiolā. 允许我进来。 |
| duhaden | 不许/不要 | — |
| haden | 建议 | — |
| nen | 难道 | — |

### 11.2 强调句

| 强调词 | 功能 | 示例 |
|--------|------|------|
| ce | 强调整句话或主语 | Ce ko bela lowo ga! 这朵花真美啊！ |
| θi | 强调指代（单数）"就这个" | θi hi dose ko mono ga! 就是他干的！ |
| θin | 强调指代（复数）"就这些" | θin es wia libon. 就这些是我的书。 |

强调某一语法成分时，将整个成分连带其示词一并提前至句首做领语。

## 规则12：结语（Endo）

结语位于句末，表达情感、语气及礼貌。结构为"前止词 + 后止词"。

### 12.1 后止词

后止词是结语的语气底座，共三种，可单用。

| 后止词 | 语气类型 | 示例 |
|--------|----------|------|
| yo | 陈述 | Ŝi es bela yo. 她是漂亮的。 |
| ga | 感叹 | Ko es ce-bela ga! 这太美了！ |
| ne | 疑问 | Ni eto sosenio ne? 你去学校吗？ |

反义疑问句使用 une：Ni etole sosenio une? 你去了学校，不是吗？

### 12.2 前止词

前止词表达说话者的情感、态度或主观判断，不可单用，必须后接后止词。

#### 普通前止词（部分）

| 前止词 | 情感/语气 | 示例 |
|--------|-----------|------|
| te- | 新动作的出现 | Hi etole teyo. 他开始去了。 |
| me- | 显而易见 | Ko es bona meyo. 这显然很好。 |
| le- | 已经到达某种状态 | Wi mōjele leyo. 我已经懂了。 |
| qo- | 确认本来如此 | Go es vedai qoyo. 那确实是真的。 |
| handê- | 喜悦 | Win sakile handêga! 太好了！我们成功了！ |
| nōn- | 愤怒和厌恶 | — |
| cesioŋ- | 惊讶 | — |
| mi- | 使语句委婉可爱（yo→o） | Ko es bela mio. 这挺美的哦。 |
| so- | 醒悟、顿悟 | Ko mono soyo! 原来如此！ |
| sē- | 特别、非常、最 | Wi dāske mōli sēga! 我最喜欢粉色啦！ |

#### 疑问专用止词

| 疑问止词 | 功能 |
|----------|------|
| ne | 一般是非问（吗） |
| ane | 半信半疑（吧） |
| nie | 委婉/询问意见（啦/吗） |
| ya | 可爱语气（呀） |
| nānna | 期待回复（好吗） |
| yen | 问原因（为什么） |
| nē | 选择（还是） |
| esdē / nesdē | 反义疑问 |

#### 能愿前止词

| 态 | 前止词 | 功能 |
|----|--------|------|
| 未然态 | sēē- | 将/将要/会 |
| 必然态 | devi- | 应/应当/该 |
| 命令态 | handen- | 最好/要 |
| 意愿态 | deθi- | 想/想要 |
| 估价态 | mezi- | 值得 |
| 能力态 | gâhi- | 会（表能力） |
| 能力态 | povi- | 能/可以 |

### 12.3 分句结语：中顿后止词 de

一句话未完成时，前面的分句结语位置用 de 提示加逗号，最后一个分句结语用 ga/yo/ne 终止。

```
示例：Hi parle de, hi hapele de, hi dormele yo. 他说了，他笑了，他睡着了。
```

---

## 语法核心要点总结

1. **语序**：默认 S + V + O，但示词使语序可自由调整
2. **示词系统**：15 个示词标记句法角色，是田语核心
3. **三种句型**：变化句（不及物）、关系句（系动词）、变化关系句（及物）
4. **动词体系统**：9×2 体词尾，逆向体表被动
5. **单谓语原则**：一个标准句只能有一个核心述元
6. **构词法**：（前缀）+ 词根 +（后缀），词缀可层层叠加
7. **结语系统**：前止词（情感）+ 后止词（语气），模块化组合
